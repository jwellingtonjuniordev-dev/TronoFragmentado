# MVP 0.7.5.1 — Correção de venda de equipamentos fabricados

A lista de venda no servidor foi ampliada para aceitar:

- Lâmina de presas: 110 ouro por unidade
- Escudo reforçado: 95 ouro por unidade
- Armadura de pedra: 180 ouro por unidade
- Escudo do saqueador: 240 ouro por unidade

A venda continua a exigir proximidade do Ferreiro, quantidade disponível e confirmação no cliente pelo botão direito. Lotes: 1, 5, 10, 20 e 50. Não foram alterados os atributos, as receitas, as probabilidades de forja, os sistemas de combate nem a persistência.

**Instalação:** parar servidor e Godot, fazer backup da base SQLite centralizada, extrair o ZIP numa pasta nova e iniciar o servidor dessa pasta. Não copiar uma base antiga sobre a base centralizada.
