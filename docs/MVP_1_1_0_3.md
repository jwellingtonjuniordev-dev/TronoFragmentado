# MVP 1.1.0.3 — Reparação do atlas do Mago

O atlas anterior tinha partes do corpo cortadas nos limites das células de 96×112. Foi substituído por 16 quadros completos de Mago, nas quatro direções, sem escudo. A composição foi ajustada para o formato 384×448 exigido pelo cliente.

Instalação: fechar Godot; substituir apenas `mvp/client/assets/visual110/hero_mage.png` (ou copiar a pasta `mvp/client` do ZIP); reabrir Godot e aguardar importação. Não substituir `characters.sqlite3`.

Nota: o Guerreiro e Arqueiro não foram modificados nesta versão. O servidor permanece inalterado.
