# MVP 1.0.5 — Cripta: primeira etapa de navegação

## Implementação no pacote ZIP
- Navegação por clique nas células livres da Cripta, com procura de percurso BFS.
- Obstáculos e célula ocupada pelo inimigo são evitados no planeamento local; o servidor continua a validar os passos.
- WASD cancela o percurso por clique.
- Caminho visualmente destacado.
- Alcance na Cripta por classe: Guerreiro 1 casa, Mago 2 casas, Arqueiro 3 casas.
- Mantidas quatro salas, progressão, recompensas e persistência anterior.

## Limitações
A Cripta continua com movimentação tática por grelha nesta versão. Não é ainda exploração contínua em tempo real. Testes de sintaxe Python e integridade ZIP passaram; teste visual Godot pendente.

## Sincronização
Esta publicação contém apenas documentação. Os ficheiros de código do MVP 1.0.5 estão no ZIP, e **não foram enviados ao GitHub nesta publicação**. Não substituir SQLite.
