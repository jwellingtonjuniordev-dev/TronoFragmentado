# MVP 1.0.7.1 — Guardiã do Armazém

- NPC `Guardiã do Armazém` junto ao Ferreiro, em (665, 310), com roupa azul e símbolo de baú.
- Aproxima-te até 85 unidades e pressiona **B** para abrir o armazém. Pressiona **B** para fechar.
- O servidor valida a distância **em cada transferência**, impedindo depósitos e levantamentos remotos mesmo com pedidos WebSocket modificados.
- NPC tem colisão no cliente e servidor; nós de recursos não reaparecem em cima dele.
- A mochila, os equipamentos individuais, os encantamentos e os dados SQLite anteriores são preservados.
