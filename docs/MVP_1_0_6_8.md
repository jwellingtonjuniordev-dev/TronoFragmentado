# MVP 1.0.6.8 — Mochila com filtros, pesquisa e ordenação

## Alterações
- Filtro de categoria: Todos, Equipamentos, Materiais, Consumíveis e Missão.
- Filtro de raridade: Todas, Comum, Incomum, Raro, Épico e Lendário.
- Ordenação: nome (A-Z), quantidade (decrescente) e raridade (decrescente).
- Campo de pesquisa por nome: clicar para escrever, Enter/Esc para sair da edição, Backspace para apagar, clique direito no campo para limpar.
- Clicar nos controlos de tipo, raridade e ordenação percorre as opções.
- A paginação, comparação, equipar, consumir e vender operam somente sobre os itens visíveis; o servidor continua a validar ações.
- Item de missão `Selo das Ruinas` é categorizado como Missão; a proteção de venda do servidor permanece intacta.
- A interface não altera o inventário persistido.
- Corrigida a tabela `EQUIPMENT_RARITY` da versão fornecida pelo utilizador (aspas já corrigidas no ZIP recebido).

## Instalação
Substituir `mvp/client/scripts/main.gd` no projeto local. Não substituir o servidor nem as bases SQLite.
A versão contém o sincronizador para publicar código e documentação depois da validação.
