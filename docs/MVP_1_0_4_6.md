# MVP 1.0.4.6 — Ataques básicos por classe

## Objetivo
Diferenciar visualmente o ataque básico de cada classe, evitando que Guerreiro, Mago e Arqueiro usem a mesma animação de espada.

## Implementação
- **Guerreiro:** corte com arco dourado e rasto luminoso.
- **Mago:** energia arcana violeta com esfera e partículas.
- **Arqueiro:** arco, corda e flecha estilizada com rasto verde.
- A escolha visual utiliza `profile.combat_class`.
- A apresentação de espada equipada e auras lendárias permanece associada à classe Guerreiro; equipamento e atributos continuam persistidos.
- O efeito básico é acionado pelo evento `combat_hit`; o servidor mantém cálculo de dano, alcance e recompensas.

## Limitações e testes
Efeitos são visuais locais; os projéteis básicos não são entidades autoritativas. Sintaxe Python e ZIP validados. Godot ainda precisa de teste visual nas três classes.

## Estado do repositório
A versão completa foi entregue em ZIP. O GitHub contém código-fonte anterior e **não está sincronizado integralmente** com este MVP; não substituir o código remoto antigo isoladamente sem conciliação.
