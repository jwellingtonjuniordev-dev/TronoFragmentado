# MVP 1.0.7.0 — Armazém pessoal persistente

- Abre/fecha o armazém com a tecla B, depois de carregar um herói com N.
- Dois painéis: mochila e baú; clique esquerdo guarda ou retira uma unidade.
- Roda do rato pagina ambos os lados; itens únicos mantêm id, nível e encantamento.
- Dados guardados no JSON do personagem dentro da tabela SQLite existente (`bank_items`, `bank_gear`). Sem migração destrutiva.
- O servidor valida quantidade, id único de equipamento, direção e identidade do herói; `Selo das Ruinas` não pode ser armazenado.
