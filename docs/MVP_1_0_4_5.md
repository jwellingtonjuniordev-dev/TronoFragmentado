# MVP 1.0.4.5 — Organização do HUD

## Problema
Depois da adição da barra de mana roxa, as notificações verdes de loot, XP e estado sobrepunham-se à barra de experiência.

## Alterações
- HP, mana e XP em três barras alinhadas e espaçadas.
- Separador horizontal abaixo do XP.
- Linha própria para notificações verdes e outra para mensagens de NPC.
- Atalhos de controlo organizados em duas linhas.
- Preservados os limites de clique, hotbar, combate, Cripta, respawn e mana progressiva.

## Validação
Compilação do servidor Python e integridade do ZIP concluídas. Teste visual no Godot pendente.

## Publicação
O código atualizado está no ZIP MVP 1.0.4.5. A publicação integral do código-fonte no repositório GitHub continua pendente; esta documentação não deve ser confundida com a sincronização do projeto.
