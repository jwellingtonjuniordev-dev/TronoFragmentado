# MVP 0.7.3 — Ferramentas avançadas

Novas receitas no Ferreiro (nível 6 da profissão):
- Machado de aço: 24 Fragmentos de madeira + 5 Barras de ferro + 2 Adagas enferrujadas, 55% de sucesso. Equipado: 5 fragmentos por árvore.
- Picareta de aço: 24 Fragmentos de rocha + 6 Barras de ferro + 5 Minérios de ferro, 50% de sucesso. Equipada: 90% de minério (70% base +20%).
- Kit botânico: 5 Ervas raras + 4 Tábuas de madeira + 1 Fragmento de metal antigo, 45% de sucesso. Equipado: 40% de erva (20% base +20%).

Uma ferramenta ativa de cada vez. As ferramentas antigas permanecem disponíveis. Cada tipo de ferramenta pode ser fabricado uma vez enquanto estiver na mochila ou equipado; depois de vender pode voltar a fabricar. Venda das novas ferramentas: 140, 170 e 190 ouro, respetivamente.

Para instalar: fechar servidor e Godot; fazer backup da SQLite centralizada; extrair numa pasta nova; iniciar servidor em mvp/server; abrir mvp/client/project.godot. O ZIP não inclui a base SQLite.

Validação: Python compilado e ZIP íntegro; Godot não executado neste ambiente.
